# 白话

用白话文写程序的中文编程语言。关键字是中文，全角标点直接能用，报错也是中文。

Baihua is a programming language that reads like plain written Chinese. It comes with a self-hosting compiler (Baihua → C → native program) written in Baihua itself, plus a single-file Python interpreter.

## 特点

- **像说话一样写**：`如果 分数 大于等于 90：`、`对于 名单 里的每个 名字：`、`重复 3 次：`
- **中文标点随便用**：（）【】，：；“” 这些全角符号和半角的效果一样，不用切换输入法
- **真正的编译器**：白话程序先翻译成 C，再编译成本机程序，运行时不需要 Python
- **编译器是用白话自己写的**（自举）：编译器编译自己，得到的 C 代码和种子文件一字不差
- **整数没有上限**：超过 64 位自动变成大整数
- **自动回收内存**：标记清除式的垃圾回收
- **列表、字典、文字处理、文件读写**都有内置函数
- **中文报错**：指出第几行、哪里错了；在函数里出错时，还会列出是从哪里一层层调用过来的
- **还有一个解释器**：`baihua.py` 一个文件就能直接运行白话程序，也有交互模式

## 先看一个例子

```
# 算一算全班的成绩
成绩单 = 【“小明”：92，“小红”：88，“小刚”：75】

函数 平均（表）：
    总分 = 0
    对于 表 里的每个 分：
        总分 += 分
    返回 总分 / 长度（表）

对于 成绩单 里的每个 名字：
    如果 成绩单【名字】 大于等于 90：
        等级 = “优秀”
    否则如果 成绩单【名字】 大于等于 80：
        等级 = “良好”
    否则：
        等级 = “继续加油”
    打印（格式化（“{}：{} 分，{}”，名字，成绩单【名字】，等级））

打印（“平均分：”，保留小数（平均（所有值（成绩单）），1））
```

输出：

```
小明：92 分，优秀
小红：88 分，良好
小刚：75 分，继续加油
平均分： 85.0
```

## 快速开始

需要一个 C 编译器。Mac 上如果还没有，先运行 `xcode-select --install`。目前在 macOS（Apple Silicon）和 Linux 上测试过。

```
git clone https://github.com/newguy75/baihua.git
cd baihua
cc -O2 -w -o baihuac baihuac.c -lm
./baihuac v03.bh
./v03
```

第三行用种子文件 `baihuac.c` 编译出白话编译器 `baihuac`，以后就用它来编译白话程序：`./baihuac 程序.bh` 会生成同名的本机程序。

不想编译的话，也可以用解释器直接运行（需要 Python 3.8 或更新的版本）：

```
python3 baihua.py v03.bh
python3 baihua.py
```

第二行不带文件名，进入交互模式，输入一句执行一句。

## 语法速览

```
# 变量和运算（× ÷ 和 * / 一样）
甲 = 10
乙 = 甲 × 2 + 3
打印（乙 % 7，乙 除以 2，10 / 4，9 / 3）

# 判断
如果 乙 大于 20 并且 不是 甲 是 0：
    打印（“大”）
否则如果 乙 等于 20：
    打印（“正好”）
否则：
    打印（“小”）

# 循环
次数 = 0
当 次数 小于 3：
    次数 += 1
对于 范围（1，5）里的每个 数：
    如果 数 是 2：继续
    如果 数 是 4：跳出
    打印（数）
重复 2 次：
    打印（“你好”）

# 函数
函数 平方（数）：
    返回 数 * 数
打印（平方（12））

# 函数里要修改外面的变量，先声明「全局」
计数 = 0
函数 加一（）：
    全局 计数
    计数 += 1
加一（）
打印（计数）

# 列表和字典（「、」也可以当逗号）
水果 = 【“苹果”、“香蕉”】
添加（水果，“橙子”）
价格 = 【“苹果”：3.5，“香蕉”：2】
价格【“橙子”】 = 4
打印（水果【0】，长度（水果），价格，包含（价格，“梨”））

# 整数没有上限
打印（99999999999 * 99999999999）
```

输出：

```
2 11.5 2.5 3
大
1
3
你好
你好
144
1
苹果 3 【“苹果”：3.5，“香蕉”：2，“橙子”：4】 假
9999999999800000000001
```

几条规则：

- 用缩进表示代码块，一般缩进 4 个空格。冒号后面只有一句时可以写在同一行：`如果 数 是 2：继续`
- 一行写好几句，用「。」或「；」隔开
- `#` 后面到行尾是注释
- 文字可以用 “” ‘’ 「」 『』 或英文引号括起来，里面可以写 `\n`（换行）和 `\t`
- 整数相除能整除就还是整数，不能整除就变成小数：`9 / 3` 是 3，`10 / 4` 是 2.5
- 文字加上任何东西会拼在一起：`“第” + 3 + “名”` 是 “第3名”
- 比较可以连着写：`1 小于 甲 小于 10`
- `不是` 放在前面表示「不」，夹在两个值中间表示「不等于」

| 写法 | 意思 |
|---|---|
| `大于` `小于` `大于等于` `小于等于` | > < >= <= |
| `等于` `是` | == |
| `不等于` | != |
| `并且` `或者` `不是` | and or not |
| `除以` | / |
| `+= -= *= /=` | 在原来的值上加减乘除 |
| `真` `假` `空` | 真、假、没有值 |
| `跳出` `继续` | 跳出循环、直接进入下一圈 |
| `返回` | 函数返回一个值 |
| `全局` | 在函数里修改最外层的变量 |

## 内置函数

| 函数 | 作用 |
|---|---|
| `打印（……）` | 打印，多个值之间用空格隔开 |
| `输入（提示）` | 读入一行文字 |
| `长度（东西）` | 文字、列表、字典的长度 |
| `范围（5）` `范围（1，10）` `范围（10，1，-2）` | 生成整数列表，两头都算；只给一个数时从 1 开始 |
| `整数（东西）` `小数（东西）` `文字（东西）` | 转换类型 |
| `类型（东西）` | 返回 “整数” “小数” “文字” “列表” “字典” 等 |
| `添加（列表，值）` | 加到列表末尾 |
| `删除（列表，下标）` `删除（字典，键）` | 删掉并返回被删的值 |
| `排序（列表）` | 返回排好序的新列表 |
| `随机整数（最小，最大）` | 随机整数，两头都可能取到 |
| `截取（文字或列表，开始，长度）` | 取出一段 |
| `查找（文字或列表，东西）` | 返回位置，找不到是 -1 |
| `包含（容器，东西）` | 列表、文字、字典里有没有，返回 真 或 假 |
| `分割（文字，分隔符）` `连接（列表，分隔符）` | 拆开、拼起来 |
| `替换（文字，旧的，新的）` `去空白（文字）` | 替换、去掉两头的空白 |
| `编码（字）` `字符（编码）` | 字和 Unicode 编码互相转换 |
| `格式化（“{}今年{}岁”，名字，年龄）` | 把 {} 依次换成后面的值，全角 ｛｝ 也行 |
| `保留小数（3.14159，2）` | 得到 “3.14” |
| `所有键（字典）` `所有值（字典）` `所有项（字典）` | 字典的键、值、键值对 |
| `取（字典，键，默认值）` | 有这个键就返回它的值，没有就返回默认值 |
| `读文件（路径）` `读行（路径）` | 读出整个文件、按行读成列表；打不开时返回 空 |
| `写文件（路径，内容）` `追加文件（路径，内容）` | 写入、追加到末尾，成功返回 真 |
| `命令行参数（）` | 运行程序时后面跟的参数 |
| `运行命令（命令）` | 运行一条系统命令，返回它的退出码 |
| `报错（……）` | 打印到标准错误 |
| `退出（状态码）` | 结束程序 |

## 出错时的样子

```
运行错误（第 4 行）：除数不能是 0
  >  返回 总分（成绩表） / 长度（成绩表）
调用过程（从最外层到出错的地方）：
  最外层，第 14 行：打印（平均分（【】））
  函数「平均分」，第 4 行：返回 总分（成绩表） / 长度（成绩表）
```

这是 `error.bh` 的输出。语法错误在编译时就会报出来，比如「这里需要冒号「：」，但出现的是换行」；关键字和名字连在一起写时，还会提示你在关键字前后加空格。

## 编译器的用法

```
./baihuac 程序.bh                    编译成本机程序，名字和源文件一样
./baihuac 程序.bh -o 输出名           指定输出的名字
./baihuac 程序.bh --emit-c           只生成 C 代码（程序.c）
./baihuac 程序.bh --cc clang         指定用哪个 C 编译器
```

## 它是怎么工作的

```
白话源码 → 词法分析（全角标点换成半角） → 语法分析 → 生成 C 代码（带上运行时） → C 编译器 → 本机程序
```

编译器的源码是 `baihuac.bh`，用白话写成。`baihuac.c` 是它编译自己得到的 C 代码，叫「种子」：有了种子，不需要 Python 就能编译出编译器。可以用下面的命令检查编译器编译自己的结果是否和种子一字不差：

```
./baihuac --emit-c baihuac.bh -o check.c
cmp check.c baihuac.c && echo 一模一样
```

改了 `baihuac.bh` 或 `baihua_runtime.c` 之后，这样重新生成种子：新编译器编译自己两遍，两遍结果一样，说明已经稳定了。

```
./baihuac --emit-c baihuac.bh -o /tmp/s1.c --runtime baihua_runtime.c
cc -O2 -w -o /tmp/s1 /tmp/s1.c -lm
/tmp/s1 --emit-c baihuac.bh -o /tmp/s2.c
cc -O2 -w -o /tmp/s2 /tmp/s2.c -lm
/tmp/s2 --emit-c baihuac.bh -o /tmp/s3.c
cmp /tmp/s2.c /tmp/s3.c && cp /tmp/s2.c baihuac.c && echo 新的种子做好了
```

连种子都没有的话，也可以用解释器运行编译器，从零生成种子：

```
python3 baihua.py baihuac.bh --emit-c baihuac.bh -o baihuac.c
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `baihuac.bh` | 编译器的源码，用白话写的 |
| `baihuac.c` | 种子：编译器编译自己得到的 C 代码 |
| `baihua_runtime.c` | 运行时：值的表示、垃圾回收、大整数、字典、内置函数、中文报错，会放进每个编译出来的程序里 |
| `baihua.py` | 解释器，单个 Python 文件，没有第三方依赖 |
| `demo.bh` | 基本语法演示，全部用中文标点 |
| `v03.bh` | 字典、按行读文件、格式化 |
| `error.bh` | 出错时的调用过程 |
| `fib.bh` | 递归算斐波那契数，可以用 `time ./fib` 看速度 |
| `big30.bh` | 大整数：30 的阶乘 |
